# No.2 AI Supply Hub — Demo & Product Docs

This is the “No.2 AI Supply Hub / AI 数字化供应链集采基地”的**老板演示原型 + MVP 产品资料**。原型用于演示小程序首页、集采商品、社群团购、AI 分销员资格、收益台账、OPC 入口和二期 AI 助手；资料用于研发、客户评审和 SaaS 厂商比选。

## Demo 重点路径

1. 首页 → 点击商品 → 选择自提/寄存/代发 → 确认加入采购清单；
2. 底部“团购” → 参团或生成分享素材；
3. 底部“经营台” → 查看分销资格三重校验、收益、锁客二维码；
4. 底部“收益” → 查看团队流水和待结算账单；
5. 底部“我的” → 查看 OPC 台账和 AI 助手入口。

## 运行

```bash
cd /home/ubuntu/jinlunyi-demo
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

> 本 Demo 中金额、订单、收益均为虚构演示数据，不代表收益承诺；正式系统的分销层级、结算、锁客、银行融资等规则必须经过专项法务与微信平台审核。
