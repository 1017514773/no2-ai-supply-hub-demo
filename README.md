# AI Supply Hub · 产品资料

本项目是「AI Supply Hub / AI 数字化供应链集采基地」的 **MVP 产品资料 + 可运行原型**。原型覆盖小程序首页、集采商品、社群团购、AI 分销员资格、收益台账、OPC 入口和二期 AI 助手；资料用于研发、客户评审和 SaaS 厂商比选。

## 原型重点路径

1. 首页 → 点击商品 → 选择自提/寄存/代发 → 确认加入采购清单；
2. 底部“团购” → 参团或生成分享素材；
3. 底部“经营台” → 查看分销资格三重校验、收益、锁客二维码；
4. 底部“收益” → 查看团队流水和待结算账单；
5. 底部“我的” → 查看 OPC 台账和 AI 助手入口。

## 运行（HTML 原型）

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

## 小程序运行（微信开发者工具）

仓库根目录已包含可运行的原生微信小程序工程（`miniprogram/`，覆盖 PRD 的 P0 前台完整闭环）；小程序与 `index.html` 原型互不影响。

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 「导入项目」→ 目录选择**仓库根目录**（工具会读取根目录的 `project.config.json`，其中 `miniprogramRoot` 指向 `miniprogram/`）；
3. AppID 选择「**测试号 / 游客模式**」（工程默认 `touristappid`，无需注册）；
4. 编译后即可体验，无需任何 Node 依赖与网络请求。

数据说明：默认 `config/env.js` 的 `useMock: true`，所有接口由 `miniprogram/mock/` 按《API-接口规划.md》的真实路径在本地实现，数据持久化在本机 Storage；可在「我的 → 重置数据」恢复初始种子数据。接入真实后端时仅需修改 `useMock: false` 与 `baseUrl`。

推荐体验路径：首页加购下单（三种履约：代发 / 寄存 / 自提）→ 微信支付（含重复回调幂等处理）→ 订单详情发货 / 核销 → 售后申请与客服审核（佣金负向冲销）→ 团购参团 / 开团 → 资格三重校验 → 提现资格拦截与打款回写。

> 当前版本中金额、订单、收益均为初始数据，不代表收益承诺；正式系统的分销层级、结算、锁客、银行融资等规则必须经过专项法务与微信平台审核。
